設定

人と項目

人ごとに、記録する項目を変えられます。項目を消しても、これまでの記録は保存先に残ります。

記録の保存先（GitHub）

接続コードを貼り付けると、記録が GitHub の非公開リポジトリに保存され、どの端末でも同じ記録になります。ピアノれんしゅう記録と同じ接続コードを使います。つなげないあいだは、記録はこの端末の中だけに残ります。

接続コードを作る（設定する人向け）

GitHub で作ったデータ用の非公開リポジトリと、そのリポジトリだけを読み書きできるトークンから、接続コードを作ります。トークンはこの端末の中で接続コードにまとめるだけで、ほかには送りません。

過去の記録を取り込む

変換ツールで作った取り込みファイル（.json）を選びます。同じ日・同じ項目の記録は、取り込んだ内容で置きかわります。
