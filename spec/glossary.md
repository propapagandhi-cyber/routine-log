# 用語集

正規語を1つに固定し、コード・仕様・UI で表記を揃える（SSOT の一部）。

| 正規語 | 略語 | English | 定義 |
|---|---|---|---|
| 習慣 | — | routine | 毎日続けたい行動の集まり。このアプリで記録する対象 |
| 人 | — | person | 記録の持ち主。人ごとに項目と記録を分ける |
| 項目 | — | item | 習慣の 1つ（起床・運動・柔軟・英語・ピアノなど）。人ごとに設定する |
| 記録 | — | entry | 日付 × 人 × 項目の 1件。結果と内容を持つ |
| 結果 | — | result | できた（`done`／○）・失敗（`fail`／×）・未入力（空）のどれか |
| 内容 | — | value | 記録の中身。起床の時刻、選んだ選択肢、メモの本文など |
| 基準時刻 | — | limit | 起床が「できた」になるいちばん遅い時刻。平日と休日で別 |
| 休日 | — | off day | 土曜・日曜・祝日（振替休日・国民の休日を含む） |
| 達成率 | — | rate | できた ÷（できた＋失敗）。未入力は数えない |
| 連続日数 | — | streak | 今日（未入力ならきのう）からさかのぼって「できた」が続いた日数 |
| 保存先 | — | cloud | 記録を置く Google スプレッドシートと、その Apps Script ウェブアプリの URL |
| ピアノアプリ | — | piano-log | 「ピアノれんしゅう記録」。練習時間を自動計測する別アプリ。保存先を共有する |
| 取り込みファイル | — | import file | 過去の記録を変換した JSON。アプリの設定から取り込む |
| 設定用リンク | — | setup link | 保存先の URL を含むリンク。開くと端末に保存先が設定される |
