# 要件（WHY）

「なぜその仕様にしたか」の根。各要件に **安定ID `R-n`** を振り、spec / behavior 側から `satisfies R-n` で参照する。
実装中に変わってよい（非ウォーターフォール）。変更時は `decisions/` に理由を残し、波及を `STATUS.md` に起票する。

## 背景・課題

- 2025年12月から、毎日の習慣（起床・運動・柔軟・英語・ピアノ）を記録している。
  最初はメモアプリ、2026年4月からはスプレッドシートに手で入力してきた。
- ピアノは、練習時間をマイクで自動計測する「ピアノれんしゅう記録」（`piano-log`）を別に作った。
  同じ内容を習慣の記録にも手で書き写すのは二度手間である。
- 記録は本人の分しかなく、子供の習慣を同じ形で管理できない。
- 端末ごとに記録がばらばらにならないよう、クラウドに 1か所で持ちたい。

## ユーザー価値

- 家族それぞれ（本人・長男・次男、今後増える可能性あり）が、自分の習慣を毎日すばやく記録できる。
- ピアノは練習すれば勝手に記録されるので、入力がいらない。
- スマホ・タブレット・PC のどれから開いても同じ記録が見える。
- 月ごとの表と達成率で、続いているか・どこで崩れたかが一目で分かる。
- 2025年12月からの過去の記録も同じ画面で振り返れる。

## 機能要件

| ID | 要件 | 優先度 | status |
|---|---|---|---|
| R-1 | 人ごとに記録を分けて管理できること。人は追加・名前変更・削除ができること | must | draft |
| R-2 | 起床時刻・運動・柔軟・英語を、日ごとに手入力できること（過去の日付も直せること） | must | draft |
| R-3 | ピアノは、ピアノれんしゅう記録の練習時間を人・日ごとに合計して自動で表示し、目標時間に届いたかを自動で判定すること | must | draft |
| R-4 | 記録はクラウド（ピアノれんしゅう記録と同じ Google スプレッドシート）に保存し、どの端末からも読み書きできること | must | draft |
| R-5 | 各項目は「できた／失敗／未入力」の結果と、内容（時刻・種類など）を持つこと。日ごとにメモを書けること | must | draft |
| R-6 | 起床は、平日と休日（土日・祝日）で別の基準時刻を持ち、入力した時刻から結果を自動で判定すること。判定は手で変えられること（例外の日のため） | must | draft |
| R-7 | 項目（名前・種類・選択肢・基準）は人ごとに設定で変えられること。値はコードに埋め込まない | must | draft |
| R-8 | 月ごとの一覧表と、項目ごとの達成率を表示できること | must | draft |
| R-9 | 過去の記録（メモ・スプレッドシートから変換したファイル）を取り込めること | must | draft |
| R-20 | 年間の達成率（項目 × 月）と連続日数を表示できること | should | draft |
| R-21 | 設定用リンクで、新しい端末に保存先をワンタップで設定できること | should | draft |

## 品質特性（NFR）

| ID | 観点 | 目標 |
|---|---|---|
| R-10 | 操作性 | 1日分（4項目）の入力が、アプリを開いてから 30秒以内・各項目 1〜2タップで終わる |
| R-11 | 信頼性 | 通信できないときも入力でき、つながったときに自動で送る。複数端末で同じ項目を書いたときは、あとから書いた方が残る |
| R-12 | 個人情報 | アプリのコードは公開リポジトリに置くが、記録・名前・メモは一切リポジトリに入れない。保存先の URL を知る人だけが記録を読める |
| R-13 | 互換性 | ピアノれんしゅう記録の動作と保存済みデータを壊さない |
| R-14 | 保守性 | ビルド不要（素の HTML/CSS/JavaScript）。ロジックは Node.js で単体テストできる |

## 外部制約（与件）

- 配信は GitHub Pages（無料枠のため公開リポジトリ）。サーバーは持たない。
- 保存先は Google スプレッドシート＋Apps Script ウェブアプリ（`piano-log` と共通の 1本）。
- 主な端末は iPad／iPhone の Safari と、PC のブラウザ。
- ピアノれんしゅう記録（`piano-log`）は稼働中。人の ID（`p1` など）と記録の形式は既存のまま使う。

## 成功指標

- 手入力のスプレッドシートをやめ、このアプリだけで毎日の記録が続く（1か月、記録もれなし）。
- ピアノの欄を一度も手で入力しない。
- 3人それぞれの記録が、どの端末でも同じ内容で見える。
